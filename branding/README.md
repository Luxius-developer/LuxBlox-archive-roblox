# LuxBlox artwork

`icon.png` and `wordmark.png` are the current source images for Android branding. The icon uses a restrained slate palette and a flat geometric mark so it sits naturally on the Android launcher. The wordmark identifies the project as LuxBlox and Vortix Studio, with 2010 as a visual reference to the era.

`tools/patch_branding.py` applies the images to the reviewed Android resources and the two reviewed loading-screen images in the OBB. It leaves third-party acknowledgements intact. In particular, the About screen's “FMOD от Firelight Studios” line credits the FMOD audio engine and is not the app publisher credit; Vortix Studio is shown separately as the project studio.
