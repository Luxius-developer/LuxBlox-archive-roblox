# Android R8 — совместимость встроенных вкладок

Package `com.luxius.luxblox`, versionCode 974. Ключ подписи сохранён. Установка поверх R7 не требует удаления приложения. SHA и точный размер: [android-r8-audit.json](android-r8-audit.json).

## Исправления клиента

В дополнение к R7 исправлены три пропущенных сборщика адресов: LuaChat WebApi, Network покупок и Shell Http. У WebApi был парсер с фиксированными `sub(13)`/`sub(12)`, предполагающий www-поддомен. У Http и Network были замены https://www в BaseUrl, которые не совпадали с origin Render. Теперь сервисы используют один HTTPS-origin и пути `/games/`, `/chat/`, `/avatar/` и т. д. Также исправлены URL миниатюры игры и ресурсов AvatarViewportFrame.

MorePageSettings дополнен короткой обёрткой над исходным модулем. Она сохраняет исходные пункты и обе структуры списка (плоскую/группы), добавляет нативную плитку «Админ-панель» для owner ID 2 и единственного QA ID 3, а также «Запустить 3D-плейс». Разрешения `/admin` проверяются сервером по ID владельца или таблице project_admins. Скрытие плитки не является механизмом авторизации.

Подписи исправлены внутри скомпилированных таблиц локализации: одних Android strings.xml было недостаточно. Строка FMOD убрана с футера «Сведения»; авторство звуковой библиотеки сохранено на `/info/licenses`, куда ведёт страница сведений. FMOD не переименован в Vortix Studio.

Реальные модули извлекаются из проверенного DataModelPatch.rbxm. Формат Luau v1 изучен по первичному исходнику Luau release 501, commit d01addc625369edd3b0edd595436576ec51f62b1. Локальный harness выполняет нормализованный байткод с тестовыми сервисами: адрес игр, адрес чата, инициализацию Network, локализацию и все варианты меню для владельца/обычного пользователя. Это не эмулятор Android и не проверка рендера.

В старой сборке лежала неиспользуемая копия `assets/main.1.com.roblox.client.obb.bak` размером 62 424 100 байт. Она удалена. Сам рабочий OBB сохранён; внутри изменён только DataModelPatch. Все десять нативных .so побайтно совпадают с R7. Уменьшение APK связано с этой лишней копией.

## Исправления сервера

- Полные scales и basicBodyColorsPalette для редактора R6, currently-wearing и пустой список ещё не созданных outfits.
- Пакетные и headshot/bust-миниатюры, legacy avatar-thumbnail/json, собственная миниатюра игры и imageToken в каталоге.
- LuaChat: participants.targetId, conversationTitle, initiator, ISO-время сообщений и lastUpdated; resultType=Success и conversation в ответе создания беседы; latest messages, typing и mark-as-read.
- Нужные страницы /careers, /parents, /info/terms и /notificationstream/embedded.
- Карточки заявок/друзей, разделы профиля, страница Premium в старой структуре с честным перечнем доступного и подарком по username.
- Повторное использование TLS-соединений PostgreSQL через ограниченный пул вместо подключения заново для каждого вспомогательного запроса. Бесплатное засыпание Render/Neon этим не отключается.

В production удалены четыре лишних служебных пользователя (ID 1,4,5,6), ID 3 переиспользован как единственный LuxBloxQA с новым паролем и ролью администратора. Его старые сеансы и служебная переписка удалены. Luxius ID 2 и неидентифицированный аккаунт test ID 7 сохранены. Проверки больше не создают случайные аккаунты на production: только локальная/CI/изолированная тестовая база.

## Проверки и границы

Локально: 50 unit/API проверок, 2 PostgreSQL-проверки пропущены из-за ограничений подключения этой среды. CI запускает те же проверки с PostgreSQL 16 на Python 3.10 и 3.12. Отдельный CI запускает пять реальных модулей Luau из закреплённой R7. Подпись v1/v2/v3 и zipalign проверены.

Штатная галочка не подключена. Модель User этой версии не читает hasVerifiedBadge; самодельная галочка не возвращалась. Встроенный 3D-редактор не заменён веб-анимацией, но его визуальная работа после R8 ещё требует проверки на телефоне. Статические миниатюры профилей не являются 3D-редактором.

RCC не запущен. Успешный вход в карту, физика, репликация и игровой чат не подтверждены. Карточка обби и лайки — данные API; они не доказывают игровую сессию. NativeLaunch передаёт запрос штатному обработчику игры. Отдельный Linux-контейнер Pterodactyl без root/изменения startup не гарантирует запуск найденного Windows RCC 0.450 или совместимость с клиентом 0.477. Для следующего шага добавлен безопасный `hosting/probe_game_host.py`; он только сообщает ОС, архитектуру, лимиты cgroup и наличие runtime, не трогая другие процессы.

## Повторная сборка

1. Получить R7 с SHA из verify_native_r8.py, распаковать Apktool 3.0.3.
2. `bash tools/build_luau_compat.sh /tmp/luxblox-luau`.
3. `python -m tools.verify_native_r8 /path/LuxBlox-r7.apk --compiler /tmp/luxblox-luau/luau-compat`.
4. `python -m tools.patch_native_r8 /path/decoded --compiler /tmp/luxblox-luau/luau-compat`.
5. versionCode 974; Apktool build; zipalign/подпись существующим закрытым ключом, который не хранится в Git.
