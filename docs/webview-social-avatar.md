# Друзья, аватар и постоянные настройки

Обновление R7: верхняя веб-навигация и рисованная галочка убраны, SVG-редактор больше не предлагается как аватар. Нативные изменения описаны в [android-r7.md](android-r7.md); ниже — история веб/API-этапа R6.

Релиз APK R6: https://github.com/Luxius-developer/LuxBlox-archive-roblox/releases/tag/android-r6

Серверное обновление расширяет API и страницы существующих WebView R5/R6. Новая APK для этих страниц не требуется. Вход браузера: `/login`; аккаунт тот же, что в приложении. Из приложения разделы доступны через «Справка» и ссылки аккаунта; `/more` содержит список разделов и для владельца пункт «Админ-панель» после сведений/справки. Отдельная новая плитка в нативном More-меню ещё не внедрена.

- Друзья: `/users/friends`, заявки, принятие/отклонение, удаление. Тот же граф обслуживает `/friends/v1/...`. Случайные пользователи не могут подтвердить чужую заявку.
- Каталог: три оригинальные рубашки (6001–6003) с собственными XML/PNG-ресурсами и три цветовых пресета (9001–9003). Пресеты отделены от реальных Roblox Asset-типов. Бесплатное получение, принадлежность, надевание и R6 bodyColors сохраняются. В native inventory API рубашки — AssetType 11.
- Аватар: `/my/avatar` показывает персонажа и редактор цветов. `/avatar/v1/avatar` отражает сохранённые цвета и одежду. PNG миниатюры также отражают цветовую схему; SVG используется только в WebView. Нативная 3D-вкладка не проверена на телефоне.
- Карточка мини-обби: `/games`, описание, реальные уникальные голоса пользователей. `isPlayable` остаётся false, потому что RCC не запущен. Сообщение о недоступном сервере отображается страницей LuxBlox; это не полученный от игрового сервера Kick.
- Robux: бесплатные наборы только для owner ID 2. Для других аккаунтов отображаются цены, крупнейший набор 10000 — 1500 ₽; покупка ведёт на 404. Платежи не обрабатываются.
- Premium: владелец может активировать себе или подарить существующему пользователю. Статус постоянный и возвращается API. Дополнительных игровых бонусов пока нет.
- Безопасность: выход из остальных сеансов; изменение пароля уже отзывает остальные сеансы. Уведомления/приватность сохраняются; отключение сообщений и заявок реально запрещает их получение, закрытый инвентарь недоступен другим. Push-доставка не реализована, настройки уведомлений пока не создают систему push.
- Админ-панель: Premium и галочки сохраняются и отображаются в WebView-профилях/списках и публичном API. Наличие поля `hasVerifiedBadge` не гарантирует, что старый нативный клиент 2021 умеет рисовать значок.

Идентичность владельца проверена по существующему пользователю Luxius, ID 2. Смена username не передаёт права новому владельцу старого имени. Админские записи журналируются в БД. Все изменения требуют авторизации и CSRF. Серверные тесты не подтверждают Android end-to-end поведение.
