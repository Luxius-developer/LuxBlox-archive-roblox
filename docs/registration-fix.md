# Исправление регистрации 2026-10-29

Пользователь подтвердил запуск LuxBlox Test (2021) на TECNO и открытие формы
регистрации. Дата рождения и пол проходили проверку, никнейм и пароль — нет.

Логи Render подтвердили 404 на `/signup/is-username-valid` и
`/signup/is-password-valid`. Обработчики APK требуют поля `IsValid`,
`ErrorCode`, `ErrorMessage` с указанным регистром; success ErrorCode=0.
Добавлены эти маршруты, единые правила валидации при создании аккаунта и
аутентифицированный `/users/account-info` для классической проверки сессии.

Локально прошли 17 тестов. Исправление развернуто commit
`d278dc9f8659658e1aaca9f0260873d43f8ac406`, deploy
`dep-dbhhpf15efls738r9qu0` (live). Пересборка APK не требуется. Внешняя HTTPS-проверка подтвердила оба валидатора,
создание аккаунта, `/users/account-info`, занятой никнейм и вход через `/v1/login`.

Аккаунты создаются отдельно в LuxBlox. Пароли/сессии Roblox и Korone не
переносятся. Пользовательские пароли и query string в app-логи не записываются.
SQLite на Render остаётся временной по решению пользователя.

После повторной проверки регистрации на телефоне: устранить следующие
отсутствующие маршруты, затем заняться иконкой, полным названием LuxBlox и
оставшимися надписями Korone. Загрузка APK в GitHub Releases пока не выполнена:
плагин не предоставляет upload/create release, а вход в облачный браузер
остановился на Google; пользователь сообщил о недоступном открытии браузера.

Пользователь затем подтвердил успешную регистрацию и вход на телефоне. Следующая
задержка после входа разобрана отдельно в [post-login-fix.md](post-login-fix.md).
